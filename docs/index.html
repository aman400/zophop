Visual Automation

Drag & Drop Workflow Graph Nodes

Chain nodes together visually to parse incoming SMS or notification payloads, check conditions, format data, and dispatch alerts.

⚡ Triggers & Logic Nodes

  • SMS Trigger: Triggers on SMS matching sender allowlists (`*BANK*`) & keyword regex.
  • App Notification Trigger: Intercepts app push notifications by package name (`com.whatsapp`).
  • Regex Parser: Extracts verification codes using regex (`\b\d{4,8}\b`) into dynamic keys.
  • JSON Parser: Parses nested JSON responses (`data.user.id`, `items[0].code`).
  • Condition Evaluator: Branches execution based on `EQUALS`, `CONTAINS`, `REGEX_MATCH`, `GREATER_THAN`, `IS_EMPTY`.

📤 Action Nodes & Delivery

  • ntfy Push Action: Sends alerts to ntfy topics with priority, tags, and title headers.
  • Gotify Push Action: Delivers alerts to Gotify servers with application tokens.
  • HTTP Webhook Action: Sends `POST`, `PUT`, `GET` HTTP requests with custom JSON body and vault auth headers.
  • Send System Notification: Displays local system notification alerts on Android.
  • Send Outgoing SMS: Transmits outgoing SMS messages to configured recipients.

Getting Started

Installation & First-Time Setup

Step 1: Install APK & Grant Android Permissions

Download ZopHop-v2.0.0.apk and install on Android 8.0+. When Google Play Protect prompt appears, tap "More details" → "Install anyway".

ADB Shell # Optional: Grant runtime SMS permission via ADB on test devices
adb shell pm grant dev.zophop android.permission.RECEIVE_SMS

Step 2: Server Deployment Examples

Run ntfy or Gotify using Docker Compose:

docker-compose.yml (ntfy) version: '3.8'
services:
  ntfy:
    image: binwiederhier/ntfy
    command: [serve]
    environment:
      NTFY_BASE_URL: https://ntfy.example.com
      NTFY_AUTH_DEFAULT_ACCESS: deny-all
    ports: ["8080:80"]

Troubleshooting

OEM Background & Battery Optimization Fixes

Aggressive OEM power managers can delay background SMS receivers. Configure autostart and battery exemption for your phone model:

📱 Xiaomi / Redmi / POCO (MIUI & HyperOS)

  1. Autostart Permission: Open Security App → Permissions → Autostart → Toggle ON for ZopHop.
  2. No Restrictions: Open Settings → Apps → Manage Apps → ZopHop → Battery Saver → Select No Restrictions.
  3. Lock in Recents: Open Recent Apps → Press & hold ZopHop window → Tap Lock Icon 🔒.
