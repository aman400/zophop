Developer Ecosystem

Build Custom External Plugins via AIDL

Publish any standalone Android APK implementing INodePluginService. ZopHop discovers it automatically, generates its config UI, injects Vault credentials, and merges its outputs into ExecutionContext.

Consume the SDK via JitPack (No Token)

app/build.gradle.ktsdependencies { implementation("com.github.aman400.zophop:plugin-api:v3.0.0") }

Public Maven artifacts are served via JitPack (no token needed), with standalone .aar files attached to GitHub Releases.

OEM Background & Battery Optimization Fixes

Select your device brand for the exact settings to prevent background SMS/notification delays:

Xiaomi / Redmi / POCO (MIUI & HyperOS)

  1. Autostart: Security App → Permissions → Background autostart → Toggle ON for ZopHop.
  2. Unrestricted Battery: Settings → Apps → Manage Apps → ZopHop → Battery Saver → No Restrictions.
  3. Lock in Recents: Open Recents → Press & hold ZopHop → Tap Lock.

Samsung Galaxy (One UI)

  1. Settings → Apps → ZopHop → Battery → Select Unrestricted.
  2. Settings → Device care → Battery → Background usage limits → Never auto sleeping apps → Add ZopHop.

OnePlus / Oppo / Realme (OxygenOS & ColorOS)

  1. Settings → Apps → App Management → ZopHop → Battery usage → Enable Allow background activity & Allow auto launch.

Google Pixel / Stock Android

  1. Settings → Apps → ZopHop → App battery usage → Allow background usage → Unrestricted.
